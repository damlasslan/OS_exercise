# Student Homework Guide · Practice edition

Use a fictional code and choose a system. Open Start / resume practice. Reuse the same browser, case and code to reopen your work.

1. Draw the components on paper. Label each process, its threads and the shared resources. Describe which thread can block and why.
2. Draw a CPU timeline. Start with the first available job. For Round Robin, append unfinished work to the queue after admitting new arrivals. Waiting time equals completion minus arrival minus burst.
3. Trace both reads and both writes of the counter. Predict the result before running each interleaving. Explain how a mutex changes the sequence.
4. Draw one column per page reference. Record the frames and count each missing page as a fault.
5. Divide file size by block size and round up. Check whether there is a sufficiently long sequence of adjacent free blocks. Compare the locking examples.
6. Record initial predictions before revealing results. Use the correction field to explain any difference. Compare CPU, memory, disk and thread measurements under two synthetic workloads. Record units and sampling intervals.
7. Export practice JSON for your records. Print the page to PDF. Practice exports do not constitute a final submission.
