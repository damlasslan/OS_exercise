# Student Homework Guide

Institutional enrollment is closed. Use a synthetic account issued for the development lab. The practice link requires only a fictional code and saves to this browser.

1. Sign in, choose one of the five systems, and start your attempt. Reopen an existing attempt from Assignments on another device.
2. Draw the system as components connected by arrows. Label data, threads, shared resources and ownership. Export the diagram as PNG under 1.2 MB. Upload it under Architecture diagram.
3. Read your personal arrivals, bursts and quantum. Trace Round Robin with a ready queue. Admit new arrivals before requeuing the running process. Waiting time equals completion minus arrival minus burst. Enter the average across all processes.
4. For the counter, write down each process's read, add and write. Predict the final value before running. Compare it with the mutex trace. Explain circular wait if two processes acquire two locks in opposite orders.
5. Track each page reference in three frames. For LRU, evict the page used least recently. Count faults. Compare your prediction with the FIFO, LRU, OPT and Clock traces.
6. Divide file size by block size and round up. Compare contiguous, linked and indexed storage. Inspect what a reader sees during a write with and without locking.
7. Enter each initial prediction before selecting **Lock prediction and run**. It remains part of your submission. Explain corrections in the separate text field.
8. Measure baseline CPU, memory, disk and threads using a system monitor. Repeat during a safe increased workload. Record units, duration and observations. Crop personal information from both screenshots and upload each as PNG.
9. Wait for **Saved to the server** before switching devices. While disconnected, keep the same browser profile. Reconnect to sync pending edits. If another device edited the draft, review the server copy before choosing which text to save.
10. Review the report. Use **Print report or save as PDF** and select Save as PDF. Choose **Submit final report** once and check the submission timestamp. Export the submitted report for UBIS. An instructor can reopen a submission if a revision is authorized.
