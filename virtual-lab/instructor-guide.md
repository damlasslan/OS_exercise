# Instructor Guide · Practice edition

Open preview.html through the static site. Choose a fictional code and repeat the same case to reproduce its workload. Use a different fictional code to demonstrate a second workload.

Review original predictions alongside corrections. Ask students to justify one scheduling decision, one page eviction and one lock acquisition. Use the assignment rubric: architecture 10, processes and threads 10, CPU scheduling 15, synchronization 15, virtual memory 20, file systems 20 and engineering evaluation 10.

The preview stores text locally and has no authenticated grading or submission service. Treat practice printouts as rehearsal material. Keep real enrollment closed pending institutional approval and verification of the authenticated release.
